隐私政策

本政策适用于页剪扫描的 iPhone 和 iPad 版本。应用在你的设备上处理扫描件。

相机权限

你开始扫描时，应用请求相机权限，用于拍摄纸质文档。你可以在设备的「设置」中关闭页剪扫描的相机权限。关闭后，应用将无法进行新的扫描。

数据收集

应用无需注册或登录，应用内没有广告、跟踪或使用情况分析。应用不会将扫描件、相机内容或使用数据发送给开发者。

扫描件的保存和清除

当前扫描页保存在应用内存中。你可以在扫描页列表中点按「返回」，确认后清空当前扫描。应用不会为你保留扫描历史。

轻点一页会将图片复制到系统剪贴板。长按一页打开系统分享菜单时，应用会生成一个临时 PNG 文件，并在应用释放该分享项目时尝试删除临时文件。

你可以自行选择分享或保存的位置。剪贴板同步、已粘贴的内容以及已保存或发送的副本，由系统或你选择的接收方管理。清空当前扫描后，如需删除这些副本，请前往对应位置单独处理。

网站和反馈

本站由 GitHub Pages 托管，公开反馈由 GitHub Issues 提供。提交公开反馈时，你的 GitHub 用户名和提交内容可能对他人可见。GitHub 对网站访问和反馈数据的处理，请参阅其隐私声明。

如有关于本政策的一般问题，请前往使用帮助。请勿在公开反馈中提交个人信息或扫描件。
